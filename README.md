# 🎓 Student Dashboard – Frontend

A modern and responsive **Student Dashboard** frontend project built using **HTML, CSS, and JavaScript**.

The project allows students to enter their details and access a dashboard where they can view their profile, courses, attendance, marks, fees, timetable, and notifications.

## 🚀 Features

* 🧑‍🎓 Student Details Registration
* 🏠 Modern Student Dashboard
* 👤 Student Profile
* 📚 Courses Information
* 📊 Attendance Percentage
* 📝 Academic Marks
* 💳 Fee Details
* 🗓️ Class Timetable
* 🔔 Notifications
* 🚪 Logout Function
* 💾 Student data stored using Local Storage
* 📱 Responsive design for desktop and mobile
* 🖱️ Clickable dashboard cards and navigation
* 🎨 Modern gradient and glass-style UI

## 📊 Dashboard Modules

### 👤 Profile

Displays the student's personal and academic information such as:

* Student Name
* Register Number
* Department
* Year
* Email
* Phone Number

### 📚 Courses

Displays the student's current semester subjects, course codes, and credits.

### 📊 Attendance

Displays subject-wise attendance percentages.

### 📝 Marks

Displays internal marks and grades for different subjects.

### 💳 Fees

Displays:

* Total Fees
* Paid Fees
* Pending Fees
* Fee Status

### 🗓️ Timetable

Displays the weekly class schedule.

### 🔔 Notifications

Displays important academic announcements and reminders.

## 💾 Data Handling

Student details entered on the first page are stored in the browser using **Local Storage**.

The project also contains a `data.json` file for storing sample student, course, attendance, marks, fees, timetable, and notification data.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Use **Live Server** in VS Code for the best experience.
5. Enter the student details.
6. Click **Enter Student Portal**.
7. Explore the clickable dashboard modules.
